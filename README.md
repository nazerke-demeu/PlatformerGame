# PlatformerGame

2D mobile platformer made in Unity 6 for the Game Development course.

## Features
- Main menu, three levels, boss fight, win screen
- Mobile controls: on-screen stick, JUMP and FIRE buttons
- Pause menu (Resume, Restart, Menu)
- Safe Area support for phones with notches

## Controls
- Keyboard: A/D or arrows to move, Space to jump, X or left mouse button to shoot
- Mobile: on-screen stick and buttons

## Assets
- Pixel Platformer by Kenney (CC0): https://kenney.nl/assets/pixel-platformer
